# Security policy

This policy applies to every repository in the `trader-os` organization (part of the Moraph portfolio).

## Reporting a vulnerability

Please **do not** report security vulnerabilities through public GitHub issues, discussions or pull requests.

- Follow the Moraph vulnerability reporting policy: https://trust.moraph.com/vulnerability-reporting
- Or email **security@moraph.com** (as published in https://www.moraph.com/.well-known/security.txt)

Include as much of the following as you can:

- The affected repository, component and version or commit
- A description of the issue and its potential impact
- Step-by-step instructions to reproduce, including any proof-of-concept code
- Any suggested mitigation

We will acknowledge your report, keep you informed of progress, and credit you (if you wish) once a fix is released.
